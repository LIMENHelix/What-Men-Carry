# What Men Carry

A platform for video and community around men's mental health, fatherhood, divorce, PTSD, and recovery.

Built by LIMEN Helix.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Videos

Videos are cinematic and visual-first — they play silently by default as you scroll. Each video can have an optional **Grok voiceover** (dramatic reading of the quote). Viewers enable audio with a click (bottom-left corner button).

### Adding Videos

Videos live in `~/Desktop/GROK Videos/` on your machine.

### Workflow

1. Drop a new video file into `~/Desktop/GROK Videos/`
2. Run `npm run sync-videos`
3. Edit `content/videos.json` and fill in the quote and theme
4. (Optional) Add the YouTube video ID
5. **Generate a Grok voiceover** (see below)
6. Run `npm run dev` to preview

The sync script will:
- Copy the video to `/public/videos/`
- Generate a poster image
- Optimize the video for web (if ffmpeg is available)
- Add a stub entry to `videos.json` with `audioFile` field

### Generating Voiceovers with Grok API

Voiceovers are generated automatically via Grok's voice synthesis API:

1. Set your Grok API key:
   ```bash
   export GROK_API_KEY=your_api_key_here
   ```

2. Fill in the quote in `content/videos.json`

3. Run sync-videos:
   ```bash
   npm run sync-videos
   ```

The script will:
- Copy videos to `/public/videos/`
- Generate poster images
- **Auto-generate voiceovers** via Grok API (dramatic, emotional read)
- Create `public/audio/{slug}-voiceover.mp3` files

Viewers toggle audio on/off with the speaker button (bottom-left corner) on each video. Videos play silently by default; voiceover is opt-in.

### Video Metadata

Edit `content/videos.json` to add:

```json
{
  "slug": "video-slug",
  "file": "video-slug.mp4",
  "title": "Short, single-line title",
  "theme": "Fatherhood | Divorce | Work | PTSD | Loss | Recovery | Addiction | Responsibility",
  "poster": "/posters/video-slug.jpg",
  "youtubeId": "dQw4w9WgXcQ",
  "date": "2026-08-20"
}
```

## Adding Events

Events are in `content/events.json`. Each event:

```json
{
  "title": "Warrior Boot Camp",
  "city": "Austin, TX",
  "date": "2026-09-15",
  "time": "7:00 AM",
  "description": "...",
  "link": "https://..."
}
```

Only future events (date > today) are displayed on the Brotherhood page.

## Site Structure

```
/app
  layout.js         – Root layout with Header and Footer
  page.js           – Home page
  /series           – Full video library with filters
  /brotherhood      – Community events and meetups
  /talk             – Talk spaces (form + info)
  /resources        – Crisis support and mental health resources
  /about            – About LIMEN Helix
  globals.css       – Global styles

/components
  Header.js         – Navigation
  Footer.js         – Footer with crisis numbers
  VideoCard.js      – Video player card component

/content
  videos.json       – Video metadata
  events.json       – Event data

/public
  /videos           – Video files (generated by sync)
  /posters          – Video poster images (generated by sync)

/scripts
  sync-videos.js    – Syncs videos from ~/Desktop/GROK Videos/
```

## Design

- **Dark, cinematic palette**: near-black backgrounds, muted steel/amber accents
- **Typography**: Crimson Text serif for body and headings, JetBrains Mono for UI
- **Mobile-first**: Built for Instagram, Facebook, YouTube shared links
- **Minimal copy**: Titles do the emotional work; no over-explanation
- **Native video players**: Muted autoplay on scroll, tap to unmute, silent loop
